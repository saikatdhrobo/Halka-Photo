# Halka Photo

Halka Photo is a fast, web-based image compressor and resizer designed to run completely in the browser. It allows users to reduce image file sizes and adjust dimensions efficiently without compromising privacy, as no files are uploaded to an external server.

## Features

* Image Compression: Adjust the quality scale from 1 to 100 to significantly reduce file sizes.
* Custom Resizing: Manually set target width and height or use the aspect ratio lock to change dimensions proportionally.
* Format Conversion: Convert images instantly between popular formats including JPG, PNG, and WEBP.
* Real-Time Preview: View the original image alongside the optimized output to compare visual quality and check file size reductions before downloading.
* High Privacy: All processing happens client-side, meaning your images never leave your local device.

## How to Use

1. Drop an image into the designated area or click to select a file from your device.
2. Configure your desired width, height, compression quality, and output format using the control panels.
3. Use the Maintain Aspect Ratio checkbox if you want to keep the original image proportions.
4. Click the Compress Image button to generate your optimized file.
5. Review the compressed size and reduction percentage metrics.
6. Click Download to save the optimized image to your device.
